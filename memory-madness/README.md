Hello, this is my third game that I have completed. Memory Madness comes from Richard Allbert and Martyna Olivares on Udemy https://www.udemy.com/course/jumpstart-to-2d-game-development-godot-4-for-beginners/?src=sac&kw=jumpstart+to+2d.
I took this course to get a better understanding on how UI works in Godot since I've struggled with that in the past.

During my time working on this project I have learned how to format UI efficently and effectively.
I have learned how to modulate how many memory tiles are dependent on what level is selected using a Godot resource and calling it LevelSetting. This LevelSetting could be attached to different instances of the level selection buttons that would tell the game script how to change the size of the grid and reset after completing or exiting the level.
I have also learned how to make a fully interactive game that is only based in a Master scene. Which contains both the main menu screen and the game screen and be able to fluidly change between one another with out issue.

I would like to learn some of the other Control/UI nodes that were not used in future projects in order to know when they are viable and when they shouldn't be used.

I still don't know how call_deferred works and when to use it. I also don't know yet how some UI nodes can be so animatable like I've seen in other games, but I have a feeling that they are used when trying to make themes for Control Nodes.

In other news I have started to read a game design book made by the creator of RimWorld. This book has taught me how every little thing in a game causes micro emotional reactions, Mechanics should be simple and easy to understand not bloated and difficult to understand, and how players decisions to do things should be taken into consideration when they try to do different things. This means that if a player can interact with an event instead of just watching and waiting for it too happen they should be able to do it so it doesn't break their immersion in the game.
I have also started to jot down different ideas on a game that has stuck with me for a while. This game is definitely something I want to make in the future just unsure if this should be my first game that I publish on Steam and other game market platforms.
